# Shamma Fathima's Birthday Surprise 💗

A mobile-friendly birthday surprise website made with HTML, CSS, and JavaScript. It works without a backend or API.

## Open in VS Code
1. Extract the ZIP file.
2. Open the `shamma_birthday_surprise` folder in VS Code.
3. Open `index.html` in your browser. Recommended: use the VS Code **Live Server** extension and click **Go Live**.

## Add your own photos
1. Put four photos in the `photos` folder.
2. Rename them exactly:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
3. If your images are PNG, either convert them to JPG or update the matching filenames in `index.html`.
4. Refresh the page. Use photos you have permission to share.

## Publish a public link with GitHub Pages (free)
1. Create or sign in to a GitHub account at https://github.com
2. Create a new **public** repository, for example `shamma-birthday-surprise`.
3. Upload `index.html`, `style.css`, `script.js`, and the `photos` folder with your images. Keep the folder structure unchanged.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub Pages will show your public website URL on the Pages settings screen. Open it on your phone to test it, then send that URL to Shamma on WhatsApp.

## Before sharing
- Test every button and make sure all photos appear.
- A public link may be opened by anyone who receives it. Only upload photos you are comfortable sharing.
- This website has no login, database, or internet API. The page itself needs an internet connection when hosted publicly, and the decorative Google Fonts may fall back to system fonts if unavailable.
